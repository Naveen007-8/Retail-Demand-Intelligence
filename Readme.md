# Retail Demand Intelligence
### Retail Sales Optimization & Demand Forecasting

## Project Overview
An end-to-end retail analytics project integrating sales data, simulated ERP inventory data and simulated marketing metrics to analyze demand patterns, forecast future sales and support inventory replenishment decisions.

## Business Objectives
- Analyze retail sales performance and demand patterns.
- Identify high-performing products and stores.
- Evaluate pricing, promotions and marketing metrics.
- Forecast product demand.
- Calculate inventory KPIs, safety stock and reorder points.
- Provide data-driven replenishment recommendations.

## Technology Stack
- Python: Pandas, NumPy, Scikit-learn, Statsmodels
- SQL: Oracle SQL
- Visualization: Power BI, DAX, Matplotlib, Plotly
- Development: VS Code, Jupyter Notebook
- Version Control: Git and GitHub

## Data Sources
- Retail sales, calendar and pricing: Walmart M5 Forecasting dataset.
- ERP inventory, purchase orders and stock movements: Simulated project datasets.
- Marketing campaign and performance metrics: Simulated project datasets.

**Note:** Simulated ERP and marketing records are illustrative and are not actual Walmart business records.

## Project Structure
- `data/` – Source and processed datasets
- `Python/` – Data cleaning, integration, analytics and forecasting
- `SQL/` – SQL scripts and data modelling
- `PowerBI/` – Power BI dashboard
- `documentation/` – Business requirements and project documentation
- `outputs/` – Reports and analytical outputs
- `models/` – Forecasting models
